# Lab 06 Computing Fundamentals

 - We started with installing Luanti via the command: flatpak install flathub org.luanti.luanti
 - We then ran Luanti and opened the user directory, making a directory called "games" in that.
 - We then installed logic lab and extracted it to that directory, ensuring that it was not nested too deep within.
 
 
 - We started with creating a door that can open/close depending on the combination of levers used(NOT all up or down), we used a combination of boolean values (Boolean logic gates as well as mesecon wires). We also used sticky pistons in the creation of the door.

 - We then created a light swtich via a lamp and 1 boolean logic gate (XOR), ensuring that when one switch is changed the light was on. If both levers were enabled/disabled it would turn off.

- We then created a simple logic machine using 2 levers, a lamp and sticky pistons. You could move the lamp
  over, up, and turn it on.

- This was the end of our lab assignment.
